# Blood visual baseline

`blood-stains-before-dynamic-rerouting.png` records the accepted persistent-stain and 2.5D runoff presentation before dried-path routing was added.

The invariant is that active wet pooling, segmented trail shapes, stain persistence, surface binding, and the overall density/variation remain intact. The only intended change is what happens when fresh blood reaches fully dried runoff: it should usually establish an adjacent lane, or visibly widen the old lane when reusing it.

`blood-stains-after-dynamic-rerouting.png` is the dry-then-respill reference generated by `--dynamic-runoff-snapshot`. It retains the older dark dry paths while showing the fresh adjacent/widened wet response.

`blood-stains-after-front-face-fix.png` locks the ordinary factory-face occlusion rule: segmented trails remain continuously visible over solid tile interiors, while the existing solid-surface clip still permits real geometric gaps/openings to interrupt the paint.
